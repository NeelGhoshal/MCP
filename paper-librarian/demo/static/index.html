Paper Librarian

A live instance of the paper-librarian MCP server: a searchable library of research papers. Call its tools directly and inspect the exact JSON-RPC messages a client like Claude exchanges with it, or ask a question and watch an assistant decide which tools to call.

Run it locally with Claude

The server runs on your machine and keeps the library in ~/.librarian. Add it to Claude Code:

claude mcp add paper-librarian -- uvx --from "git+https://github.com/NeelGhoshal/MCP#subdirectory=paper-librarian" paper-librarian

or to Claude Desktop's claude_desktop_config.json:

{
  "mcpServers": {
    "paper-librarian": {
      "command": "uvx",
      "args": ["--from", "git+https://github.com/NeelGhoshal/MCP#subdirectory=paper-librarian", "paper-librarian"]
    }
  }
}

This demo shares one library among all visitors, so remove_paper and add_note are disabled, add_paper accepts arXiv ids only, and anything added is lost when the server restarts. Source: github.com/NeelGhoshal/MCP.

Built on the MCP Python SDK 2.x. The “Ask” mode uses an open model through Groq to stand in for Claude; the tool calls are real.
