Run it locally with Claude

Install from PyPI (needs uv). The server runs on your machine and keeps your own library in ~/.librarian, so you can add any arXiv paper or PDF. Claude Code:

claude mcp add paper-librarian -- uvx paper-librarian

Claude Desktop, in claude_desktop_config.json:

{ "mcpServers": { "paper-librarian": { "command": "uvx", "args": ["paper-librarian"] } } }

Or connect to this server by URL

Search this demo's library from Claude without installing anything. In claude.ai or Claude Desktop, open Settings → Connectors → Add custom connector and paste the URL below. In Claude Code:

claude mcp add --transport http paper-librarian https://<this-site>/mcp

The URL endpoint is read-only: you can search and read the papers already here, but not add or remove them.

This demo shares one library among all visitors, so remove_paper and add_note are disabled, add_paper accepts arXiv ids only, and anything added is lost when the server restarts. Source: github.com/NeelGhoshal/MCP.

Built on the MCP Python SDK 2.x. The “Ask” mode uses an open model through Groq to stand in for Claude; the tool calls are real.
